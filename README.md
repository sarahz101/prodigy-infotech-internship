**Python Cybersecurity & Cryptography Exercises**

A collection of Python-based cybersecurity exercises demonstrating fundamental concepts in cryptography, password security, image encryption, keylogging, and network packet analysis.

**Tasks Included**
**Caesar Cipher** — Encrypts and decrypts text using a configurable shift key with support for uppercase and lowercase letters.
**Image Encryption** — Performs basic pixel-level image encryption and decryption using NumPy and modular arithmetic.
**Password Strength Validator** — Checks passwords against common security requirements including length, uppercase/lowercase characters, digits, and special characters.
**Keylogger** — Demonstrates keyboard event monitoring and logging using pynput.
**Packet Sniffer** — Captures and displays live network packet summaries using the Scapy library.

These exercises were developed to practice Python programming and foundational cybersecurity concepts, including classical cryptography, authentication security, system monitoring, and network analysis.

Note: The image encryption and keylogger implementations are intended for educational purposes and demonstrate basic cybersecurity concepts rather than production-ready security solutions.
